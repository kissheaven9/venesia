# Венеция — фабрика шпонирования

Архивная копия сайта, сделанного Ольгой Тихомировой на Tilda (оригинал: venesia.tilda.ws). Сохранена для портфолио.

- Статическая копия: 22 страницы, все изображения, стили и скрипты лежат локально в `tcdn/`.
- Счётчики аналитики заказчика удалены, страницы закрыты от индексации (`noindex`).
- Формы заявок отключены: показывают пояснение, ничего не отправляют.
- Каталоги магазина показывают то же состояние, что и оригинал на момент копирования (09.11.2026).
